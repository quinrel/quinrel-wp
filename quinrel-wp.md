
# Quinrel - Visibility & Discovery Intelligence for WordPress


Quinrel for wordpress goes beyond your regular seo-plugin to connecting your site to the quinrel's discovery intelligence infrastructure that help you understand, monitor and improve how your brand is discovered across search, social media, AI answers, maps, directories and other emerging discovery surfaces. 
This enables the plugin to perform:
* discovery checks 
* AI visibility observations 
* citations 
* SERP observations 
* competitor observations 
* entity data 
* schema observations 
* indexing status 
* technical discovery signals 
* location-specific discovery 
* historical visibility 
* alerts 
* recommendations

## Positioning 
Be discoverable everywhere

## Architecture
Quinrel For WordPress provides quinrel's visibility and discovery intelligence inside wordpress. 


The plugin has two operating modes:
### Standalone Mode - works without a Quinrel account. 
A wordpress native quinrel client that provides immediate utility to the user without being connected to the quinrel's api (api.quinrel.com)

Then a connect button to Unlock the full Discovery Intelligence report

The full seo features is documented inside
@docs/features.md

Local capabilities remain local. Cloud capabilities are additive i.e If api.quinrel.com goes down, the WordPress site must continue functioning normally.

### Quinrel Connected
The user optionally connects the plugin to Quinrel Visibility & Discovery Intelligence API to unlocks the capabilities of Quinrel's infrastructure inside wordpress. This requires the site to be authenticated on api.quinrel.com. 
Connected Quinrel account unlocks:
* discovery monitoring
* AI visibility
* competitor intelligence
* alerts
* recommendations
* historical intelligence
* quick fixes
* an action plan inside WordPress

- Someone searches WordPress.org for keywords related to SEO, Discoverability, etc
- The user installs Quinrel.
- The user initially uses the standalone version for free:
- Then Quinrel shows them something much more interesting:

Connect Quinrel

## Authentication

Connect site
→ Quinrel issues a site-specific credential
→ plugin stores it securely
→ scoped permissions
→ token rotation/revocation
→ API rate limits
→ site-level identification.

# Quinrel documentation

A careful WordPress site can still be hard to find. Quinrel is the on-site place for the titles, the social cards, the sitemap, the redirects, the schema, and the audit, and an optional connection to Quinrel for intelligence, quick fixes, and an action plan from the Quinrel API.

Visibility & Discovery Intelligence for WordPress, with technical SEO included.

Technical SEO works with no Quinrel account. A Quinrel account is optional. It does not score AI mentions, Google presence, or competitors. The plugin does not invent those results on the site.

Start with [About Quinrel](about.md) and the [feature list](features.md). The WordPress.org description is `readme.txt` in the plugin root. If a page below disagrees with those, follow the feature list and the readme.

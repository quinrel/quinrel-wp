# Coming soon

These items are not in the current plugin. The screens in [features.md](features.md) are what you can use today.

- Search Console connect that does not ask for a Google Cloud client ID and client secret.
- A count of citations in ChatGPT, Perplexity, Google AI Overviews, or Claude. Quinrel can record crawler visits on this site for 30 days, and only when the request reaches WordPress. That record is not a citation count.
- Suggested internal links that are written only after an editor approves them. The editor already suggests internal links. It does not insert them on its own.
- Notes on a heading or paragraph, and a rule that blocks publishing until an SEO check is signed off.
- A workspace for more than one brand, and a dashboard that manages more than one site.
- A broken-link scan that runs off the site for very large libraries. The Broken Link Checker on this site scans published content in small batches.
- A client reporting portal, including a page a client can open and a PDF you can send.
- Schema import from a page whose JSON-LD appears only after JavaScript runs. Import from the HTML of a public page is already available. Private and local addresses are not fetched.
- A private AI endpoint such as Azure OpenAI or Amazon Bedrock, and a log of each prompt. The writing assistant today uses an OpenAI, Anthropic, or Ollama key saved on this site.
- A separate PHP package of the SEO rules for Laravel, Symfony, or a Node backend.

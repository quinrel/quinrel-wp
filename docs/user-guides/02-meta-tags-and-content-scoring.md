# Titles and the editor

Open a post in the block editor. The Quinrel panel is where you set what search and social previews can show for that post.

## What the panel checks

- SEO titles and meta descriptions
- Readability, using Flesch Reading Ease
- A search-result preview
- Social metadata for Facebook, X, LinkedIn, and Pinterest
- Canonical URLs and robots meta
- FAQ schema
- Internal link suggestions
- A notice when cornerstone content has not been updated for 180 days
- PageSpeed for the post you are editing

The document title stays with the theme unless a custom SEO title is saved. While Yoast, Rank Math, All in One SEO, or SEOPress is active, Quinrel does not replace titles and meta until an administrator confirms it.

The Bulk Meta Editor is the screen for changing SEO titles and meta descriptions across many posts, so a missing title does not require opening each one.

## Writing assistant

The writing assistant uses an OpenAI, Anthropic, or Ollama key saved on this site. A remote Ollama host receives the text you submit. It runs when an editor asks it to run. Ollama defaults to this server. A settings import cannot switch it to a remote host.

The assistant does not publish the post, and it does not check whether an AI product mentions the site.
